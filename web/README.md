# PETs Transformer web app

A local web app around the engine: upload data or pick a challenge sample, describe the recipient, check what Detect found, run the
release gate, and download the protected data and its evidence.

It runs on your own machine and has no sign-in, so never expose it to a network. Uploaded data, keys and row maps stay in
`../workspace/`, which git ignores, and the API only ever serves the protected release, the evidence and the dashboard.

## Setup

From this folder, with the challenge package next to the repository and the repository's `.env` holding `PETS_ENGINE_KEY`:

```bash
cd backend
python3 -m venv venv
venv/bin/pip install -r requirements.txt -e ../../../TRUSTED_PETS_PROVING_GROUND_2026/toolkit
cp .env.example .env
cd ../frontend
npm install
```

## Run

Two terminals:

```bash
cd backend && venv/bin/uvicorn app.main:app --port 8000
```

```bash
cd frontend && npm run dev
```

Then open http://localhost:5174. API documentation is at http://localhost:8000/api/docs/.

After changing the API, regenerate the frontend's typed client while the backend runs:

```bash
cd frontend && npm run openapi-ts
```

## How it fits together

| Part | What it does |
|---|---|
| `backend/app/routers/` | Translate HTTP only: samples, scenarios, datasets, runs |
| `backend/app/services/` | Register data, cache Detect's answer, write the run's scenario and review files, run the engine in the background one run at a time |
| `frontend/src/features/release/` | The four steps, the run page and their hooks |
| `frontend/src/api/generated/` | The typed client, generated from the backend's OpenAPI document |

Each run folder in `../workspace/runs/` keeps the scenario and review a person chose, next to the engine's usual output, so every
release can be traced back to the decisions behind it.

## Where this came from

The project skeleton was generated with [blacksmith-cli](https://github.com/theblacksmithdev/blacksmith-cli) 0.1.25
(`blacksmith init web --type fullstack --backend fastapi --frontend react`), a pre-existing open-source tool. Its sign-in system,
database and template pages were removed. Files still marked "Generated by Blacksmith" come from that skeleton. Everything in
`features/release`, `pages/new-release`, `pages/run`, the backend's routers, services and schemas, and the engine was written at the event.
